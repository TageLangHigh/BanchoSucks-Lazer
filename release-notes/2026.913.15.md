**Updates installieren sich jetzt beim Start**
- Behoben: Seit dem ersten Release hat der Client nie nach Updates gesucht, der Updater war gar nicht eingebunden. Deshalb musste jede neue Version von Hand installiert werden. Wer noch 2026.913.14 oder älter hat, installiert dieses eine Mal noch BanchoSucksLazer-win-Setup.exe (Einstellungen, Maps und Scores bleiben erhalten). Danach nie wieder.
- Neu: Beim Start prüft der Client unsere Releases und installiert eine neuere Version sofort, mit Fenster und Ladebalken, bevor das Spiel startet. Wie bei osu!: öffnen, kurz warten, fertig. Ohne Internet startet das Spiel nach wenigen Sekunden normal.
- Während einer längeren Sitzung wird weiter alle 30 Minuten geprüft; ein dann gefundenes Update lädt im Hintergrund und wird per Hinweis zum Neustart angeboten.

**Updates now install at startup (English)**
- Fixed: since the first release the client never looked for updates, the updater was not wired in at all, so every new version had to be installed by hand. If you are still on 2026.913.14 or older, run BanchoSucksLazer-win-Setup.exe one last time (settings, maps and scores are kept). Never again after that.
- New: on startup the client checks our releases and installs a newer version right away, with a popup and progress bar, before the game starts. Like osu!: open, wait a moment, done. Without internet the game starts normally after a few seconds.
- During a longer session it keeps checking every 30 minutes; an update found then downloads in the background and offers a restart in a notification.
